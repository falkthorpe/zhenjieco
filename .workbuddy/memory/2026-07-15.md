## BUG FIX (16:46): privacy/terms pages showed "no content"
- **Symptom**: privacy.html (and same for terms.html) appeared blank/"没有内容".
- **Root cause**: `<main class="doc reveal">` wrapped the ENTIRE long document in `.reveal`. `js/main.js` reveals `.reveal` via IntersectionObserver with `threshold: 0.12` + `rootMargin '0px 0px -60px 0px'`. For a very tall element, 12% of its height exceeds the viewport height, so the threshold is never met → `.is-visible` never added → stays `opacity:0`. Other pages apply `.reveal` to small elements, so they worked.
- **Fix**: removed `reveal` from `<main class="doc reveal">` → `<main class="doc">` in both privacy.html and terms.html. Content now always visible; page-header inner reveals (eyebrow/h1/lead) still animate fine.
- **Lesson**: never wrap a full-length document/article in a single `.reveal`; either omit reveal on the wrapper or apply reveal to small blocks only.
